The tiny fixtures were generated locally using FFmpeg 8.1.2. No ffmpeg executable is used by the tests.

- bframes.mp4: 12 H.264/yuv420p frames at 10 fps; has_b_frames=2. Exercises decoder EOF drain.
- hevc10.mp4: 7 HEVC/yuv420p10le frames at 10 fps. Exercises higher bit-depth pixel conversion.
- mjpeg.avi: 5 MJPEG/yuvj444p frames at 10 fps. Exercises full-range JPEG source decoding.
- hls/: the H.264 fixture remuxed as a local VOD playlist and MPEG-TS segment, served over loopback HTTP.

Regenerate with:
```sh
ffmpeg -f lavfi -i testsrc2=size=64x48:rate=10 -frames:v 12 -c:v libx264 -bf 3 -g 12 -pix_fmt yuv420p bframes.mp4
ffmpeg -f lavfi -i testsrc2=size=64x48:rate=10 -frames:v 7 -c:v libx265 -x265-params log-level=error -pix_fmt yuv420p10le hevc10.mp4
ffmpeg -f lavfi -i testsrc2=size=64x48:rate=10 -frames:v 5 -c:v mjpeg -pix_fmt yuvj444p mjpeg.avi
ffmpeg -i bframes.mp4 -c copy -an -hls_time 1 -hls_list_size 0 hls/index.m3u8
```

Color/stride/concat fixtures are lossless YUV4MPEG files generated by the test program.
